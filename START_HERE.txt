FOOTBALL FACT-FIRST RESEARCH v7.0.1 — SEARCH RESCUE + STABILITY + INDEPENDENT AI COUNCIL

WHAT CHANGED
- Added a bounded Gemini Google Search grounding rescue when cloud-hosted HTML search returns zero usable evidence.
- Added Setup → Test Web Research with provider-by-provider diagnostics.
- Empty-search errors now explain which providers failed instead of claiming the fixture has no public evidence.
- Fixed the broken v6.3 service worker and made PWA registration failures visible.
- package.json is now the single runtime version source.
- Added real AI Council preflight testing: Gemini, OpenRouter, Groq and Cloudflare are actually called.
- The deterministic statistical checker is separate and NEVER counts as an AI Council vote.
- Council targets are now 3/4/6/8 independent AI models instead of misleading 8/25/50/100 agent seats.
- Added hard timeouts to AI provider calls so one stalled provider cannot freeze the whole round.
- Reduced quota waste and improved failure reporting.
- Extended in-memory job retention from 45 to 90 minutes.
- Browser research deadline is 20 minutes.

DEPLOYMENT — MOBILE FRIENDLY
ROOT OF GITHUB REPOSITORY:
  server.js
  package.json
  package-lock.json (if included)
  env.example (reference only; do not upload secrets)

INSIDE public/:
  index.html
  service-worker.js
  manifest.webmanifest
  icon-192.png
  icon-512.png

RENDER
Build command: npm ci (use npm install if package-lock.json is not present)
Start command: npm start

AFTER DEPLOYMENT
1. Open the Render URL while you have data/Wi-Fi.
2. Go to Setup.
3. Tap Recheck Setup.
4. Paste a fixture and tap Test Web Research.
5. Confirm WEB RESEARCH READY (Tavily or Gemini Google Search rescue).
6. Tap Test AI Council.
7. Do not trust the Council label unless it says AI COUNCIL READY.
8. Recommended Council size: 4 independent models.

IMPORTANT
A working API-Football key does NOT prove that the AI Council works. Test them separately.
