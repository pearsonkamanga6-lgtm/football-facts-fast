FOOTBALL FACT-FIRST RESEARCH v3.0 — MULTI-AI COUNCIL + POSTBOARD

Use this v2 package instead of v1.

1. Create a NEW GitHub repository, for example:
   football-factfirst-research

2. Upload ALL files/folders from this extracted v2 folder.

3. In Render:
   New -> Web Service
   Connect the new repository
   Runtime: Node
   Build command: npm install
   Start command: npm start
   Plan: Free

4. In Render -> Environment add:
   API_FOOTBALL_KEY
   TAVILY_API_KEY
   GEMINI_API_KEY
   GEMINI_MODEL = gemini-3.8-flash   (optional)

5. Save changes and redeploy.

6. Open the app -> Setup.
   It must show:
   API-Football: connected
   Tavily: connected
   Gemini: connected

7. Click "Test API-Football Key".
   It should report that the key works and show daily quota remaining.

8. Research fixtures using:
   Home Team vs Away Team

AUTHENTICITY RULE:
If current club/squad identity is not verified, the app will not allow a STRONG conclusion.

NEW IN v2.2
===========
TWO START MODES
1. I WILL GIVE THE GAMES
2. FIND DATA-RICH GAMES FOR ME

AUTO-DISCOVERY DOES NOT USE ODDS TO CHOOSE GAMES.
It uses structured competition coverage and fresh public-source availability.

ALL MARKET FAMILIES ARE SCREENED BEFORE PRICES.

VALUE WATCH
After the sporting shortlist is completed, the app fetches bookmaker odds,
calculates break-even probability and compares it with the model's fair-probability estimate.
Potential value requires at least +5 percentage points of estimated edge.

The report clearly separates:
- sporting evidence
- market-family screen
- shortlist
- bookmaker price audit
- potential value alerts
- source links
- video review


NEW IN v2.3 — RESEARCH PIPELINE
================================
MODE 1: I GIVE THE GAMES
MODE 2: APP FINDS DATA-RICH GAMES

Every selected fixture then follows:

1. DATA GATHERING
   Get current structured data, live public sources, source links and video evidence.

2. DATA ANALYSIS
   Compare, normalize, adjust for opponent strength, identify patterns/contradictions,
   screen all market families, score evidence and exact shortlisted markets.

3. PRESENTATION
   Show:
   - market bar chart
   - data-coverage pie/donut
   - evidence-quality score chart
   - written analysis
   - complete market screen
   - value audit
   - video review
   - all source links

ODDS REMAIN LAST.
